# 예산과 현금 흐름 사용법

- 예산 설정에서 달을 먼저 선택합니다. 월 총액 또는 주 평균 금액으로 입력하며, 저장되는 월 총액 하나를 주간·월간이 함께 사용합니다. 다른 달에는 자동 복사하지 않습니다.
- 월초·월말의 짧은 주도 포함해 주 배분 합계가 월 총액과 같습니다. 이전 초과 지출은 다음 주 가용 예산에서 차감하며, 설정된 이전 달의 초과분도 이월합니다.
- 식료품 예산은 생활 예산에 포함된 주별 배정액입니다. 소비 등록에서 자취 식료품 구매를 체크하면 사용액을 따로 확인할 수 있습니다.
- 지출 내역의 조회 날짜와 화살표로 기간을 변경합니다. 월 경계의 하루짜리 주도 별도로 조회됩니다.
- 지출 등록은 원래 결제액과 본인을 포함한 나눌 인원을 받습니다. 나누어떨어지지 않는 1원은 본인 부담으로 계산합니다. 생활 예산에는 본인 부담액을 반영하고, 현금 흐름에는 실제 결제한 전체 금액을 반영합니다.
- 정산 받음을 체크하고 받은 날짜를 지정해야 다른 사람의 몫이 현금 유입으로 반영됩니다. 현재 정산은 전액 수령 여부를 기록합니다.
- 상단 현금 흐름에서 시작 잔액·기준일, 카드 마감일, 마감 월로부터 출금 월, 결제일을 사용자별로 저장합니다. 여러 카드에 공통된 한 결제 기준을 사용합니다.
- 카드 마감일 31, 다음 달, 결제일 15는 전월 1일~말일 사용분을 다음 달 15일에 출금하는 설정입니다. 해당 일자가 없는 달은 말일에 출금합니다.
- 할부는 원금·개월 수·첫 납부 월로 등록합니다. 생활 예산에는 넣지 않고, 현금 흐름과 소비 분석에서 매월 납부액을 계산합니다. 무이자 원금 기준이며 별도 이자는 포함하지 않습니다. 같은 할부 원금을 일반 지출로 중복 등록하지 마세요.
- 월말 예상 현금은 등록된 수입·출금과 받은 정산을 반영합니다. 추가로 향후 카드 결제액·남은 할부 원금·약속을 확보한 보수적인 가용 잔액을 표시합니다. 미수 정산은 수령 전까지 포함하지 않습니다.
- 약속의 날짜·예상액을 등록하면 달력에 예정 표시가 생기고, 하루 사용 가능액에서 미리 확보합니다. 실제 지출을 기록한 뒤 해당 약속을 예정 해제해야 중복 확보되지 않습니다.
- 기록과 설정은 변경 시 브라우저와 서버에 자동 저장됩니다. 반복되는 서버 저장 성공 토스트는 표시하지 않습니다. 저장 실패·충돌 알림은 유지합니다.

## 배포 시 로그인 연결

Vercel 프로젝트의 Settings → Environment Variables에 NEXT_PUBLIC_SUPABASE_URL과 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY를 설정하고 다시 배포합니다. 공개 키의 실제 값은 저장소에 넣지 않습니다.
Supabase Authentication → URL Configuration에는 서비스 주소를 Site URL로, 로컬·배포 주소의 /account를 Redirect URLs로 등록합니다. 로컬에서 제공받은 공개 키와 프로젝트 연결 응답은 확인했으며, 실제 이메일 가입·확인은 사용자의 이메일로 진행합니다.
